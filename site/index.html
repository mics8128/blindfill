The password goes from vault to form, not through the model

The agent names an account and a page. blindfill does the rest and reports only the outcome.

Secrets stay out of the model's context

Runs on your machine. Use it as a CLI, an MCP server or a TypeScript library.

Fill-only secrets

No command or tool ever returns a password, TOTP seed or private key.

Bound to the right site

The vault item decides where a secret goes. Lookalike domains are refused before anything is read.

Locked after fill

Page text, DOM and screenshots are refused afterwards. Output is scrubbed.

Stops instead of guessing

Ambiguous fields and unknown outcomes are reported, never retried.

Get started

You need Node 20+ and the Bitwarden CLI (bw). Three commands: 

export BW_SESSION="$(bw unlock --raw)"
npx -y blindfill session start
npx blindfill fill --item <id> --url https://example.com/login --submit

No Chromium yet? Run npx playwright-core install chromium once. For agents: npx -y blindfill mcp. Daily use: npm i -g blindfill.
